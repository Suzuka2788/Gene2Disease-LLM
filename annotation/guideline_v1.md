# 标注指南 v1（草稿）

用于 E7 审计和 10 篇穷举集。写定于查看任何系统判断之前，试标后可修订一次，修订要留档。

## 单位

先标**断言**，再由规则得出配对结论。断言是论文中关于一个基因和一种疾病的一处陈述，一个配对可以有多条断言。

## 断言字段

| 字段 | 取值 | 规则 |
|---|---|---|
| polarity | positive | 文中支持两者存在关系 |
| | negative | 文中明确报告在所检验的比较中没有关系。“未检测到显著差异”只对该比较成立，不代表全文否定 |
| certainty | stated | 直接陈述 |
| | hedged | may、might、could、suggest、possibly 等 |
| relation_class | causal | 有针对这一关系的干预、扰动、致病变异或孟德尔随机化证据，或论文给出依据的明确因果断言 |
| | association | 其他所有情况，包括相关、差异表达、GWAS、生物标志物 |
| provenance | this_study | 本文自身的结果 |
| | cited_background | 引用他人的结论 |
| | unclear | 无法判断 |
| evidence_scope | local | 证据在同一句或相邻句内 |
| | nonlocal | 判断这条断言需要跨段或跨章节的内容。只在穷举集上标注 |

polarity 只描述是否支持关系。负相关是有方向的阳性关系，不是 negative。语气只由 certainty 描述。文中没有断言时，四个字段都不填。

## 配对结论

- 至少一条 positive 断言（stated 或 hedged）：是边。
- 只有 negative 断言：不是边，保留记录。
- 没有断言：不是边。
- positive 和 negative 并存：是边，全部断言都保留，并标记冲突。

## 审计流程

1. 条目顺序随机，界面相同，不显示来源系统和模型理由。
2. 先写下判断，再看系统给出的证据。
3. 可以查阅全文，不限于证据窗口。
4. 判断不了的标 `undecided`，并按预先定义的方式分别报告。

## 穷举集

对一篇论文标出全部断言，并记录工具实体清单缺失的基因和疾病。标注时可以看工具给出的实体，但不看任何关系判断。

## 证据核验的判断口径（2026-11-07 用户决定：按 BioRED 指南）

证据核验（`TWO_WEEK_PLAN.md`）中"段落是否支持这条关系"按 BioRED 官方标注指南判断。依据是 `data/biored_guideline/guideline.txt` 第 313–460 行，判 positive 必须满足：

- 文中**明确陈述**了这一基因与这一疾病的关系，不要求在同一句；
- 相关在两个方向都算：基因产物增多或减少导致、加重、预防或治疗该疾病，或者敲低、敲除基因后疾病发生改变；
- 遗传关联算：在该病患者中观察到的变异，改变患病风险的变异，或基因产物缺乏导致的疾病；
- 轻微关联也算，例如只在少数患者中观察到；
- 属于目标疾病的子类疾病，也与该基因相连。

下列情况**不算关系**：
- 基因只作为预后因子（例如表达量预测生存期），除非文中另有与疾病本身的关系；
- 目标疾病的症状与基因的关系，除非文中明确陈述；
- 表述不清楚；
- 只是推测（may、might、suggest 等），且文中没有明确陈述。按 BioRED"不清楚的不标"的规定处理，但仍把 certainty 记为 hedged，这样可以单独报告（用户 2026-11-07 确认）。

另外两条规则：
- 结论为阴性（不显著、未观察到相关）的，记为 negative。
- 每条都要分别回答两个问题：
  1. 窗口里的段落本身是否支持这条关系；
  2. 模型引用的句子是否支持这条关系。

  第 1 题不看模型的引用，第 2 题才看。

选择这个口径的理由：开发集和测试集的金标都按这个口径标注。用同一口径，核验结果才能说明，按 BioRED 定义算出的精确率里，有多少"假阳性"其实是标注遗漏，有多少是真错。
